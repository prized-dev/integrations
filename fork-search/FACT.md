On Terminal-Bench 2.1, 80 of the 89 tasks pass their reference solution in both of 2 trials on Prized sandboxes. 12 of those 80 fail their own tests when only the task's working directory is copied to a fresh machine, and 5 of the 12 fail when the processes are killed (a server or VM the tests talk to). The 12 are adaptive-rejection-sampler, build-pmars, build-pov-ray, caffe-cifar-10, compile-compcert, hf-model-inference*, install-windows-3.11*, kv-store-grpc*, largest-eigenval, nginx-request-logging*, pypi-server* and sqlite-with-gcov (* also needs a live process).
Method: no model is involved; Harbor's oracle agent runs each reference solution, 2 trials per task. When the verifier starts, and before any test runs, the machine is forked twice. In one copy the image's WORKDIR (`/app` for 77 of the 80) is packed with tar, and the tar is extracted into a fresh sandbox of the same image; in the other copy every process the trial left running is killed. Harbor's own verifier steps are replayed on both.
Control: the same tar, extracted back over the workdir of the copy it came from, passed in every trial of all 80 tasks with an identical file manifest (type, mode, size, sha256, link target), so the copying never caused a failure. No task's result differed between its two trials.
